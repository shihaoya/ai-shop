# 前端开发规范

## 一、技术栈

| 类别 | 技术 | 版本要求 |
|------|------|----------|
| 构建工具 | Vite | 8.x |
| 框架 | Vue 3 | 3.5+，Composition API + `<script setup>` |
| 包管理 | pnpm | 10.x |
| UI 组件库 | Ant Design Vue | 4.x |
| 原子化 CSS | UnoCSS | 66.x |
| 状态管理 | Pinia | 3.x |
| 路由 | Vue Router | 4.x |
| HTTP 请求 | Axios | 1.x |
| 动效 | @vueuse/motion | 2.x |
| 图标 | @ant-design/icons-vue | 4.x |

## 二、项目初始化

### 2.1 创建项目

```bash
cd code
pnpm create vite frontend --template vue-ts
cd frontend
```

### 2.2 安装依赖

```bash
# 核心依赖
pnpm add vue-router@4 pinia axios ant-design-vue@4 @ant-design/icons-vue
pnpm add @vueuse/core @vueuse/motion
pnpm add color

# UnoCSS
pnpm add -D unocss @unocss/preset-uno @unocss/preset-attributify

# 开发依赖
pnpm add -D sass
```

### 2.3 开发命令

| 命令 | 说明 |
|------|------|
| `pnpm dev` | 启动开发服务器 (端口 18781) |
| `pnpm build` | 构建生产版本 |
| `pnpm preview` | 预览构建结果 |
| `pnpm lint` | ESLint 检查 |

### 2.4 Vite 配置

```typescript
// vite.config.ts
export default defineConfig({
  plugins: [vue(), UnoCSS()],
  resolve: {
    alias: {
      '@': resolve(__dirname, 'src'),
    },
  },
  server: {
    port: 18781,
    proxy: {
      '/api': {
        target: 'http://localhost:18780',
        changeOrigin: true,
      },
    },
  },
})
```

## 四、路由规范

### 4.1 路由表结构

按角色分为：认证页、管理员、店铺用户、普通用户。详见 `src/router/index.ts`。

### 4.2 路由守卫

- 已登录访问登录页 → 跳转到对应首页
- 未登录且不是公开页 → 跳登录
- 已登录但角色不匹配 → 跳对应首页
- 账号状态异常（待审核/冻结）→ 登出并提示

详见 `src/router/guards.ts`。

### 4.3 角色首页映射

| 角色 | homePath |
|------|-----------|
| 管理员 (1) | `/admin/shops` |
| 店铺用户 (2) | `/operator/shop` |
| 普通用户 (3) | `/user/products` |

## 五、布局规范

### 5.1 布局类型

| 布局 | 说明 |
|------|------|
| AuthLayout | 登录/注册布局（居中玻璃卡片） |
| AdminLayout | 管理员布局（悬浮气泡顶栏+侧栏） |
| OperatorLayout | 店铺用户布局（同上结构） |
| UserLayout | 普通用户布局（顶栏+底部Tab导航） |

### 5.2 悬浮气泡导航

顶栏和侧栏均为悬浮气泡形态，四周留有空隙，带有完整的玻璃阴影和圆角，漂浮在页面内容之上。侧栏可折叠为仅图标模式。右下角有全局主题切换按钮。

### 5.3 侧栏折叠

- 展开状态：240px
- 折叠状态：64px（仅图标）
- 快捷键：`Ctrl+B`

## 六、样式规范

### 6.1 设计风格

**拟态玻璃（Glassmorphism）**：通透、柔光、层次感，配合细腻微动效。支持亮色/暗色模式和8色主题切换。

| `src/styles/antd-overrides.scss` | AntDV 组件玻璃化覆盖 |
| `src/styles/transitions.scss` | 页面过渡动画定义 |

## 八、API 请求规范

### 8.1 Axios 实例

封装统一的请求/响应拦截器，自动附带 Token，统一错误处理。详见 `src/api/request.ts`。

### 8.2 统一定义

```typescript
interface ApiResult<T = any> {
  code: number       // 200=成功
  message: string
  data: T
}

interface PageResult<T> {
  records: T[]
  total: number
  page: number
  size: number
}
```

### 8.3 模块划分

按功能模块拆分：`auth.ts`、`admin.ts`、`operator.ts`、`user.ts`、`upload.ts`。

## 九、状态管理规范

### 9.1 Store 划分

| Store | 职责 |
|-------|------|
| `user.ts` | 用户状态（token、角色、信息）、登录/登出 |
| `app.ts` | 应用全局状态（侧栏折叠等） |
| `theme.ts` | 主题状态（亮暗模式 + 主题色） |
| `shop.ts` | 当前店铺状态 |

### 9.2 主题状态

- 模式：`'light' | 'dark' | 'auto'`
- `auto` 模式跟随系统 (`prefers-color-scheme`)
- 配置持久化到 `localStorage`（key: `theme-config`）
- 详见 `src/stores/theme.ts`

## 十、代码规范补充

### 10.1 TypeScript

- 全局类型定义放 `src/types/`
- 按模块拆分：`api.ts`、`user.ts`、`shop.ts`、`product.ts`、`order.ts`、`points.ts`
- 使用 Composition API + `<script setup>`

### 10.2 雪花 ID 精度

后端返回 Long 类型 ID 时，前端需转为 String 处理，防止精度丢失。

### 10.3 逻辑删除

查询时注意 `deleted` 字段条件，避免查询已删除数据。

### 10.4 店铺营业状态

歇业时普通用户可浏览商品但无法下单。
