# 移动端开发计划

## 项目概述

为积分商城系统开发独立的移动端 H5 应用，采用 Vant 4.x 作为 UI 组件库，实现与 PC 端一致的业务功能，同时贴合移动端交互习惯。

## 技术选型

| 技术 | 版本 | 说明 |
|------|------|------|
| Vue | 3.5+ | 组合式 API |
| Vite | 8.x | 构建工具 |
| Vant | 4.9+ | 移动端 UI 组件库 |
| UnoCSS | 0.63+ | 原子化 CSS |
| Pinia | 2.2+ | 状态管理 |
| Vue Router | 4.4+ | 路由管理 |
| VueUse | 11.0+ | 组合式工具库 |

## 二、公共组件开发

### 2.1 布局组件

#### MobileTabBar（底部导航）
- 按角色渲染不同 TabBar
- 角色对应关系：
  - 普通用户：商品、订单、我的
  - 店铺用户：商品、订单、用户、我的
  - 管理用户：店铺、用户、我的
- 使用 `van-tabbar`
- 高亮动画
- 安全区域适配

#### ThemeSetting（主题设置面板）
- 使用 `van-popup` 从底部弹出
- 功能：
  - 亮暗模式切换（`van-switch`）
  - 主题色选择（预设色板）
  - 自动跟随系统（勾选）
- 复用 `stores/theme.ts`

#### ChangePassword（修改密码）
- 使用 `van-popup` 弹出
- 表单字段：原密码、新密码、确认密码
- 表单验证（长度、两次密码一致性）
- 提交调用 `authApi.updatePassword`

#### HeaderBar（通用头部）
- 左侧返回按钮（带安全区适配）
- 标题
- 右侧操作按钮（可选）
- 使用 `van-nav-bar`

### 2.2 通用组件

#### EmptyState（空状态）
- 图标 + 文字描述
- 可选操作按钮
- 使用场景：列表为空时展示

#### LoadingState（加载状态）
- `van-loading` 动画
- 全屏和局部两种模式

#### InfiniteScroll（无限滚动）
- 基于 `van-list` 封装
- 自动加载更多
- 加载完成/失败状态处理

#### PullRefresh（上拉刷新）
- 使用 `van-pull-refresh`
- 集成业务刷新逻辑

#### ConfirmDialog（确认对话框）
- 统一封装 `van-dialog`
- 用于删除、拒绝等危险操作确认

## 三、普通用户功能

### 3.1 登录/注册

#### Login（登录页）
- 手机号/用户名 + 密码登录
- `van-field` 表单
- 登录按钮
- 注册链接
- 加载状态
- 错误提示

#### Register（注册页）
- 表单字段：用户名、昵称、密码、确认密码、邀请码
- 邀请码使用 `van-field` 输入（非扫码）
- 表单验证
- 注册协议勾选（可选）

### 3.2 商品

#### ProductList（商品列表页）
- 顶部搜索栏（`van-search`）
- 商品分类 Tab（横向滚动 `van-tabs`）
- 商品列表（`van-list` + 无限滚动）
- **ProductCard（商品卡片）**
  - 商品图片（`van-image` 懒加载）
  - 商品名称
  - 积分价格
  - 库存状态
  - 点击进入商品详情
- 下拉刷新
- 无数据空状态

#### ProductDetail（商品详情抽屉）
- 右侧抽屉（85% 宽度）
- 内容：
  - 商品轮播图（`van-swipe`）
  - 商品名称
  - 积分价格
  - 库存数量
  - 商品描述
  - 兑换须知
- 底部操作栏：
  - 兑换按钮（跳转地址选择或直接兑换）

### 3.3 订单

#### OrderList（订单列表页）
- 状态 Tab：`全部 / 已下单 / 已确认 / 已发货 / 已完成 / 已关闭`
- 订单卡片列表（`van-list`）
- **OrderCard（订单卡片）**
  - 订单状态标签
  - 商品信息（名称、图片、数量）
  - 积分总额
  - 下单时间
  - 操作按钮（根据状态显示）
- 卡片点击进入订单详情

#### OrderDetail（订单详情抽屉）
- 右侧抽屉
- 内容：
  - 订单状态流转图
  - 商品信息（名称、图片、数量、积分）
  - 收货信息（收货人、电话、地址）
  - 物流信息（快递公司、运单号）
  - 订单编号、下单时间
- 操作按钮（根据状态显示：确认收货等）

### 3.4 我的

#### Profile（个人中心页）
- 用户头像 + 昵称显示
- 角色标签
- 积分余额显示（普通用户）
- 功能入口列表：
  - 地址管理
  - 我的消息
  - 主题设置（弹窗）
  - 修改密码（弹窗）
  - 退出登录

#### AddressList（地址列表页）
- 地址卡片列表
- **AddressCard（地址卡片）**
  - 收货人、电话
  - 完整地址
  - 默认地址标识
  - 编辑/删除按钮
- 新增地址按钮
- 默认地址设置

#### AddressForm（地址表单抽屉）
- 右侧抽屉
- 表单字段：
  - 收货人
  - 手机号
  - 省市区选择（`van-area`）
  - 详细地址
  - 设为默认地址
- 保存/取消按钮

#### MessageList（消息列表页）
- 消息列表（`van-list`）
- **MessageCard（消息卡片）**
  - 标题
  - 摘要
  - 时间

## 八、注意事项

1. **ID 类型**：所有雪花 ID 必须使用 `string` 类型
2. **抽屉优先**：详情页统一使用 `van-drawer` 从右侧滑出
3. **列表加载**：使用 `van-list` 实现分页 + 无限滚动
4. **图片懒加载**：使用 `van-image` 的懒加载功能
5. **表单验证**：使用 `van-form` + `van-field` 的内置验证
6. **安全区域**：TabBar 和底部按钮需适配 `safe-area-inset-bottom`
7. **主题联动**：修改密码、退出登录等操作后清除 `localStorage`
8. **登录拦截**：未登录用户访问需重定向到登录页
9. **重复组件**：PC 端已有组件优先复用或重写移动端版本
