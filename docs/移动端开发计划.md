# 移动端网站开发计划

## 一、概述

在现有 PC 端积分商城系统基础上，开发一套功能对等、体验优化的移动端网站（Mobile Web），覆盖管理员、店铺用户、普通用户三个角色。

### 核心目标

1. **功能对等** — 覆盖 PC 端所有业务功能，但页面设计以移动端交互为准，不照搬 PC 布局
2. **多主题色系** — 5 种主题色（冰蓝/极光紫/翠绿/玫瑰/琥珀）+ 暗色/亮色模式切换
3. **原生感交互** — 底部 Tab、滑动操作、底部弹出面板、下拉刷新、触控友好
4. **同一后端** — 对接现有 `http://localhost:18780` API

## 二、技术方案

### 2.1 架构决策

| 选项 | 方案 | 说明 |
|------|------|------|
| ✅ **选型** | 独立前端项目 | 新建 `code/mobile/`，与 PC 端 `code/frontend/` 完全隔离 |
| 备选 | 同一项目 | 已排除——用户要求互不影响 |

**理由**：完全隔离避免路由冲突、依赖冲突、构建配置互相影响；各自可独立部署迭代。

### 2.2 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | React 19 + TypeScript | 与 PC 端一致，降低心智负担 |
| 构建 | Vite | 独立配置 |
| 样式 | Tailwind CSS 4 + CSS 变量主题 | 完全自建主题系统（参考 PC 端和 demo） |
| 路由 | React Router 7 | 独立路由配置 |
| 状态 | Zustand | 新建 store |
| HTTP | Axios | 新建 request 封装 |
| 图标 | Lucide React | 独立安装 |
| 组件 | 自建移动端组件库 | 轻量、针对触控优化 |

> **注意**：stores / services / types / lib **不共用**，但严格参照 PC 端的 API 签名和类型定义进行开发，确保对接同一后端。

### 2.3 项目结构

```
code/
├── frontend/          ← PC 端（不变，不受影响）
│   ├── src/
│   │   ├── pages/
│   │   ├── stores/
│   │   ├── services/
│   │   └── ...
│   └── package.json
│
└── mobile/            ← 新建：移动端（完全独立）
    ├── src/
    │   ├── layouts/       # 移动端布局（底部 Tab）
    │   ├── pages/         # 按角色分：auth/admin/operator/user/
    │   ├── components/    # 移动端通用组件
    │   ├── stores/        # 独立 store（参照 PC 端 API 签名）
    │   ├── services/      # 独立 Axios 封装（对接同一后端）
    │   ├── types/         # 独立类型定义
    │   ├── lib/           # 工具函数
    │   ├── router/        # 独立路由
    │   ├── App.tsx
    │   ├── main.tsx
    │   └── index.css
    ├── package.json
    ├── vite.config.ts
    ├── tsconfig.json
    └── tsconfig.app.json
```

## 三、路由与页面架构

### 3.1 设计原则

| 原则 | 说明 |
|------|------|
| **扁平化** | 核心功能 3-4 个 Tab 内完成，不超 2 层导航深度 |
| **少页面多面板** | 编辑/创建类操作优先用底部弹出面板，而非独立页面 |
| **手势驱动** | 滑动操作替代右键菜单，下拉刷新替代刷新按钮 |
| **上下文敏感** | 列表项的直接操作（上架/下架、审核通过/拒绝）通过滑动即完成 |

**关键差异对比（移动端 vs PC 端）：**

| 场景 | PC 端 | 移动端 |
|------|-------|--------|
| 商品编辑 | 独立页面 `/operator/products/:id` | 底部面板弹出，不离开列表页 |

| 订单操作 | 跳转详情页操作 | 列表项滑动或点击弹出操作面板 |
| 地址编辑 | 独立页面 | 列表 + 底部面板表单 |
| 用户审核 | 跳转用户详情 | 列表滑动操作 |
| 发货操作 | 跳转发货页面 | 底部表单面板 |

## 四、页面交互设计

### 4.1 认证模块

**入口**：登录/注册 —— 全屏页面（无 Tab 导航）
- 与 PC 端共用相同的毛玻璃 + 动效背景主题
- 登录成功根据角色跳转到对应的移动端 Tab 首页
- 表单字段大触控区域（`min-h: 48px`），键盘弹出时页面自动上推

### 4.2 普通用户端

#### 商品列表（Tab 首页）

| 元素 | 说明 |
|------|------|
| 顶部 | 搜索框（可折叠）+ 分类横划标签（Chips，支持左右滑动切换） |
| 主体 | 卡片瀑布流（2 列 Grid），显示主图、名称、积分价格、库存标签 |
| 交互 | 下拉刷新 + 滚动到底自动加载更多 |
| 空态 | 插画 + "暂无商品" 提示 |
| 加载 | 骨架屏卡片（6 个占位） |

#### 商品详情 + 兑换流程 ✅ 移动端核心设计

| 步骤 | 交互方式 |
|------|---------|
| 1. 查看详情 | 从商品列表点击卡片 → 底部弹出面板（覆盖 85% 屏幕） |
| 2. 浏览信息 | 面板内展示：大图轮播 + 商品名/描述 + 积分 + 库存 + 发货说明 |
| 3. 选择数量 | 面板内步进器（Stepper）选择数量，校验限购 |
| 4. 选择地址 | 面板内切换地址（如有多地址，弹出地址选择器） |
| 5. 立即兑换 | 面板底部固定按钮 "确认兑换"，点击后调接口 |
| 6. 结果反馈 | Toast 提示成功，面板关闭，跳转到订单 Tab |

> **不跳独立下单页**：整个兑换流程在商品详情面板内完成，体验类似抖音商品购买。

## 五、UI/UX 设计

### 5.1 设计语言：Aurora Ice Mobile

继承 PC 端的 **Aurora Ice（极光冻彩）** 视觉风格，但为移动端做了交互层面适配：

| 设计要素 | 说明 |
|---------|------|
| 背景 | 暗色/亮色自适应 + 毛玻璃效果 + 浮动光晕（Orb） |
| 主题色 | 5 种可切换：冰蓝(`#3b82f6`)、极光紫(`#8b5cf6`)、翠绿(`#10b981`)、玫瑰(`#f43f5e`)、琥珀(`#f59e0b`) |
| 模式 | 暗色/亮色一键切换 |
| 卡片 | 圆角 16px + 轻阴影，无边框毛玻璃风格 |
| 触控区 | 所有可交互元素最小 44×44px |
| 字体 | 系统无衬线字体，正文 15px，小字 13px |
| 间距 | 基于 4px 网格，页面左右安全边距 16px |

### 5.2 主题切换交互

右下角悬浮主题切换器（吸底布局，与 Tab 栏不重叠）：
- 常驻一个浮动圆形按钮，点击展开为面板
- 面板内：暗色/亮色切换 + 5 种主题色色块选择
- 状态持久化到 `localStorage`

### 5.3 移动端专属交互模式

| 交互 | 实现方式 |
|------|---------|
| **底部 Tab** | 固定 48px 高度 + Safe Area 适配，图标+文字 |
| **顶部导航** | 固定 44px，左侧返回箭头 + 居中标题 + 右侧可选操作 |
| **底部面板** | 从底部上滑弹出，覆盖 60-90% 屏幕，拖拽手柄可关闭 |
| **滑动操作** | 列表项左滑显示 1-2 个操作按钮（如审核、删除） |
| **下拉刷新** | 列表页通用下拉刷新，带加载动画 |
| **无限滚动** | 列表滚动到底部自动加载下一页 |
| **骨架屏** | 所有列表页初次加载显示骨架屏 |

| **触控反馈** | 点击 `active:scale-96`，按钮 `active:brightness-90` |
| **步进表单** | 复杂表单（如商品编辑）分步引导，左右滑动切换步骤 |

## 十三、风险与注意事项

| 风险 | 影响 | 应对 |
|------|------|------|
| 移动端图片加载 | 商品图片在弱网下体验差 | `loading="lazy"` + 骨架屏占位 + 占位色块 |
| 商品编辑长表单 | 字段多、手机屏幕小 | StepForm 分步引导，每步 3-5 个字段 |
| 数据实时性 | 用户期望订单状态实时更新 | 进入页面自动拉取 + 下拉刷新 |
| 雪花 ID 精度 | 后端返回 Long，前端需 String | 类型定义确保 `id: string` |
| 底部面板高度 | 不同手机屏幕高度差异大 | 面板高度设百分比，内部滚动 |
| 键盘遮挡 | 表单输入时键盘遮挡 | `visualViewport` API + scrollIntoView |
