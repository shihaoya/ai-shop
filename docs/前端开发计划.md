### 1.1 接口响应格式

```typescript
// 成功
{ code: 200, message: "操作成功", data: {...} }

// 失败
{ code: 400, message: "错误信息", data: null }
```

### 1.2 分页请求

| 参数 | 类型 | 默认值 |
|------|------|--------|
| page | number | 1 |

## 二、Auth 认证模块 `/api/auth`

| 接口 | 方法 | 前端对应 |
|------|------|----------|
| /api/auth/login | POST | 登录页 |
| /api/auth/register | POST | 注册页 |
| /api/auth/info | GET | 获取用户信息+积分 |
| /api/auth/password | PUT | 修改密码 |
| /api/auth/logout | POST | 退出登录 |

**请求体**：
```typescript
// 登录
{ username: string, password: string }

// 注册
{ username: string, nickname: string, password: string, inviteCode: string }
```

## 八、技术要点

1. **雪花ID处理**：后端返回 Long → 前端转 String
2. **Token 携带**：请求头 `Authorization: Bearer <token>`
3. **角色路由守卫**：未登录 → /auth/login，已登录但角色不符 → 对应角色首页
4. **营业状态**：店铺歇业时，商品可浏览但不可下单
5. **虚拟商品**：发货时填 delivery_content，实体商品填 expressCompany + expressNo
