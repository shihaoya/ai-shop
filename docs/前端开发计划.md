## 六、技术注意事项

### 6.1 雪花 ID 精度

后端返回 Long 类型 ID 时，前端需转为 String 处理，防止精度丢失。

### 6.2 逻辑删除

查询时注意 `deleted` 字段条件，避免查询已删除数据。

### 6.3 店铺营业状态

歇业时普通用户可浏览商品但无法下单。

### 6.4 权限控制

- 未登录用户访问需权限页面 → 跳转登录
- 已登录但角色不匹配 → 跳转对应首页
- 账号状态异常（待审核/冻结）→ 登出并提示
