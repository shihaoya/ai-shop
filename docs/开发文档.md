# 积分商城系统 - 开发文档

## 一、技术栈

### 1.1 前端

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | React 18 + TypeScript | 使用 Vite 构建 |
| UI 组件 | shadcn/ui + Tailwind CSS | 基于 Aceternity UI 设计风格 |
| 路由 | React Router 6 | 客户端路由，角色隔离 |
| 状态管理 | Zustand | 轻量级状态管理 |
| HTTP 客户端 | Axios | API 请求封装 |
| 图标 | Lucide React | 现代图标库 |
| 包管理 | pnpm | Node.js 包管理器 |

### 1.2 后端

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | Spring Boot 3.x | Java 17 |
| ORM | MyBatis-Plus | 简化 CRUD 操作 |
| 数据库 | MySQL 8.0 | 逻辑删除，不使用物理外键 |
| ID 生成 | 雪花算法 | 转 String 传给前端避免精度丢失 |
| 安全 | JWT | Token 认证 |
| 构建 | Maven | 依赖管理和构建 |

## 四、关键设计决策

### 4.1 数据库规范

- **不使用物理外键**：通过逻辑关联维护数据一致性
- **不使用唯一键**：逻辑删除后无法保证唯一性
- **枚举类型**：用 `tinyint` + 备注替代枚举
- **删除方式**：逻辑删除，所有表都有 `deleted` 字段
- **ID 生成**：雪花算法，转 String 传给前端

### 4.2 用户角色

| 角色 | 说明 |
|------|------|
| 管理员 | 系统唯一，管理所有店铺和用户 |
| 店铺用户 | 运营自己店铺，发行积分 |
| 普通用户 | 属于某店铺，兑换商品 |

### 4.3 订单状态流转

```
已下单 (1) → 已确认 (2) → 已发货 (3) → 已完成 (4)
     ↓           ↓
   关闭(5)     关闭(5)
```

### 4.4 注册审核机制

- 店铺用户注册 → 管理员审批 → 通过后登录
- 普通用户注册 → 店铺用户审批 → 通过后登录

## 六、API 约定

### 6.1 请求格式

- Content-Type: `application/json`
- 认证: `Authorization: Bearer <token>`

### 6.2 响应格式

```typescript
// 成功
{
  "code": 200,
  "message": "success",
  "data": { ... }

// 失败

  "data": null
```

```typescript
  "message": "success",
  "data": {

    "pageSize": 10
```

## 七、路由结构

### 7.1 前端路由

```
/                          # 首页，重定向到对应角色
/auth/login                # 登录
/auth/register              # 注册

/admin/*                   # 管理员（角色=1）
  /admin/dashboard          # 管理控制台
  /admin/shops              # 店铺管理
  /admin/users              # 用户管理
  /admin/invite-code        # 邀请码管理

/operator/*                # 店铺用户（角色=2）
  /operator/dashboard       # 工作台
  /operator/shop            # 我的店铺
  /operator/categories      # 分类管理
  /operator/products        # 商品管理
  /operator/orders          # 订单管理
  /operator/users           # 用户管理
  /operator/invite-code     # 邀请码管理
  /operator/messages        # 我的消息

/user/*                    # 普通用户（角色=3）
  /user/products            # 商品列表
  /user/products/:id        # 商品详情
  /user/orders              # 我的订单
  /user/addresses           # 地址簿
  /user/center              # 个人中心
```

### 7.2 后端 API 前缀

| 端 | 前缀 | 说明 |
|---|------|------|
| 认证 | `/api/auth` | 登录、注册、修改密码 |
| 管理员 | `/api/admin` | 管理员专用 |
| 店铺用户 | `/api/operator` | 店铺用户专用 |
| 普通用户 | `/api/user` | 普通用户专用 |

## 九、注意事项

1. **雪花ID精度**：后端返回 Long，前端转为 String 处理，避免精度丢失
2. **逻辑删除**：查询时注意 `deleted = 0` 条件
3. **店铺营业状态**：歇业时普通用户可浏览但无法下单
4. **邀请码**：管理员/店铺用户可生成，普通用户注册需审核
