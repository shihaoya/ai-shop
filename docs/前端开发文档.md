# 前端开发文档

## 一、技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | React 18 + TypeScript | 使用 Vite 构建 |
| UI 组件 | shadcn/ui + Tailwind CSS | 基于 Aceternity UI 设计风格 |
| 路由 | React Router 6 | 客户端路由，角色隔离 |
| 状态管理 | Zustand | 轻量级状态管理 |
| HTTP 客户端 | Axios | API 请求封装 |
| 图标 | Lucide React | 现代图标库 |
| 包管理 | pnpm | Node.js 包管理器 |

## 三、开发命令

```bash
# 进入前端目录
cd code/frontend

# 安装依赖（首次克隆后执行）
pnpm install

# 开发服务器（热重载）
pnpm dev

# 构建生产版本
pnpm build

# 预览构建结果
pnpm preview

# 类型检查
pnpm typecheck
```

## 四、组件使用（shadcn/ui）

### 4.1 添加组件

```bash
# 通过 CLI 添加组件
cd code/frontend
pnpm dlx shadcn@latest add button
```

### 4.2 常用组件

| 组件 | 命令 | 用途 |
|------|------|------|
| Button | `add button` | 按钮 |
| Input | `add input` | 输入框 |
| Label | `add label` | 标签 |
| Card | `add card` | 卡片容器 |
| Badge | `add badge` | 状态标签 |
| Avatar | `add avatar` | 头像 |
| Dropdown | `add dropdown-menu` | 下拉菜单 |
| Tabs | `add tabs` | 标签页 |
| Table | `add table` | 表格 |
| Dialog | `add dialog` | 对话框 |
| Select | `add select` | 选择器 |
| Textarea | `add textarea` | 文本域 |
| Toast | `add sonner` | 提示消息 |

### 4.3 组件使用示例

```tsx
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Card, CardHeader, CardTitle, CardContent } from "@/components/ui/card"

function Example() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>标题</CardTitle>
      </CardHeader>
      <CardContent>
        <Input placeholder="请输入..." />
        <Button>提交</Button>
      </CardContent>
    </Card>
  )
}
```

## 五、路由结构

### 5.1 前端路由

```
/                          # 首页，重定向到对应角色
/auth/login                # 登录
/auth/register              # 注册

/admin/*                   # 管理员（角色=1）
  /admin/dashboard          # 管理控制台
  /admin/shops              # 店铺管理
  /admin/users              # 用户管理
  /admin/invite-code        # 邀请码管理

/operator/*                # 店铺用户（角色=2）
  /operator/dashboard       # 工作台
  /operator/shop            # 我的店铺
  /operator/categories      # 分类管理
  /operator/products        # 商品管理
  /operator/orders          # 订单管理
  /operator/users           # 用户管理
  /operator/invite-code     # 邀请码管理
  /operator/messages        # 我的消息

/user/*                    # 普通用户（角色=3）
  /user/products            # 商品列表
  /user/products/:id        # 商品详情
  /user/orders              # 我的订单
  /user/addresses           # 地址簿
  /user/center              # 个人中心
```

## 六、API 请求约定

### 6.1 请求格式

- Content-Type: `application/json`
- 认证: `Authorization: Bearer <token>`

### 6.2 后端 API 前缀

| 端 | 前缀 | 说明 |
|---|------|------|
| 认证 | `/api/auth` | 登录、注册、修改密码 |
| 管理员 | `/api/admin` | 管理员专用 |
| 店铺用户 | `/api/operator` | 店铺用户专用 |
| 普通用户 | `/api/user` | 普通用户专用 |

### 6.3 响应格式

```typescript
// 成功
{
  "code": 200,
  "message": "success",
  "data": { ... }
}

// 失败
{
  "code": 400,
  "message": "错误信息",
  "data": null
}
```

### 6.4 分页响应

```typescript
{
  "code": 200,
  "message": "success",
  "data": {
    "list": [...],
    "total": 100,
    "page": 1,
    "pageSize": 10
  }
}
```

## 七、注意事项

1. **雪花ID精度**：后端返回 Long，前端转为 String 处理，避免精度丢失
2. **组件路径**：使用 `@/` alias，如 `@/components/ui/button`
3. **工具函数**：使用 `lib/utils.ts` 中的 `cn()` 合并类名
