# 后端开发文档

## 一、技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | Spring Boot 3.x | Java 17 |
| ORM | MyBatis-Plus | 简化 CRUD 操作 |
| 数据库 | MySQL 8.0 | 逻辑删除，不使用物理外键 |
| ID 生成 | 雪花算法 | 转 String 传给前端避免精度丢失 |
| 安全 | JWT | Token 认证 |
| 构建 | Maven | 依赖管理和构建 |

## 三、开发命令

```bash
# 进入后端目录
cd code/backend/ai-shop

# 运行开发服务器
./mvnw spring-boot:run

# 构建项目
./mvnw clean package

# 运行测试
./mvnw test
```

## 四、数据库规范

| 规范 | 说明 |
|------|------|
| 不使用物理外键 | 通过逻辑关联维护数据一致性 |
| 不使用唯一键 | 逻辑删除后无法保证唯一性 |
| 枚举类型 | 用 `tinyint` + 备注替代枚举 |
| 删除方式 | 逻辑删除，所有表都有 `deleted` 字段 |
| ID 生成 | 雪花算法，转 String 传给前端 |

---

## 五、用户角色

| 角色 | 值 | 说明 |
|------|---|------|
| 管理员 | 1 | 系统唯一，管理所有店铺和用户 |
| 店铺用户 | 2 | 运营自己店铺，发行积分 |
| 普通用户 | 3 | 属于某店铺，兑换商品 |

## 六、订单状态流转

```
已下单 (1) → 已确认 (2) → 已发货 (3) → 已完成 (4)
     ↓           ↓
   关闭(5)     关闭(5)
```

**状态枚举**：1=已下单，2=已确认，3=已发货，4=已完成，5=已关闭

## 九、注意事项

1. **雪花ID精度**：返回 Long 给前端时需转为 String，避免精度丢失
2. **逻辑删除**：查询时注意 `deleted = 0` 条件
3. **店铺营业状态**：歇业时普通用户可浏览但无法下单
4. **邀请码**：管理员/店铺用户可生成，普通用户注册需审核
