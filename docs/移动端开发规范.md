# 移动端开发规范

## 项目信息

- **技术栈**: Vue 3.5 + TypeScript, Vite 8.x, Vant 4.x, UnoCSS, Pinia, Vue Router, VueUse
- **包管理**: pnpm
- **端口**: 待定（需与 PC 端协调，建议 18782）
- **目录**: `code/mobile/` 或 `code/frontend-mobile/`
- **模式**: 移动端 H5 应用，适配手机浏览器

## 与 PC 端差异

| 方面 | PC 端 (Ant Design Vue) | 移动端 (Vant) |
|------|----------------------|---------------|
| UI 库 | ant-design-vue | vant |
| 布局 | 侧边栏 + 主内容区 | 底部 TabBar |
| 交互 | hover/mouse | tap/touch |
| 表单 | ant-input/select | van-field/picker |
| 弹窗 | ant-modal | van-popup/van-drawer |
| 列表 | ant-table | van-list/滚动加载 |
| 移动适配 | 响应式 breakpoint | rem + viewport 适配 |

## 核心规范

### 1. ID 类型约束（最高优先级）

```typescript
// ✅ 正确 - 所有 ID 使用 string | null
interface Product {
  id: string
  shopId: string | null
}

// ❌ 错误 - 禁止使用 number
interface Product {
  id: number
}
```

**原因**: JS `Number.MAX_SAFE_INTEGER = 2^53-1`，雪花 ID 是 64 位，转 Number 会精度丢失

**禁止**:
- `Number(id)`, `parseInt(id)`, `+id`
- `id as number`
- `const numId = +id`

### 2. 组件拆分原则

#### 可复用组件（放置 `src/components/`）
- 业务无关的通用组件
- 跨角色使用的组件
- 弹框、抽屉、列表项等独立 UI 单元

#### 页面级组件（放置 `src/views/`）
- 页面主体布局 + 局部状态管理
- 页面专属弹框/抽屉可直接内联在页面内

#### 推荐拆分粒度

### 5. CSS 变量复用

移动端复用 PC 端已有的主题变量体系（`stores/theme.ts`），但需适配移动端字号和间距：

```css
/* src/styles/mobile-variables.css */
:root {
  /* 复用 PC 端主题变量 */
  --accent: var(--accent);
  --accent-rgb: var(--accent-rgb);

  /* 移动端适配 */
  --font-size-base: 14px;
  --spacing-base: 16px;
  --safe-area-bottom: env(safe-area-inset-bottom);
}
```

### 6. 亮暗主题切换

利用 Vant 的 `useTheme` 和 PC 端 `stores/theme.ts` 实现联动：

```typescript
// composables/useMobileTheme.ts
import { useThemeStore } from '@/stores/theme'

export function useMobileTheme() {
  const themeStore = useThemeStore()

  function applyTheme(mode: 'light' | 'dark') {
    document.documentElement.setAttribute('data-theme', mode)
    // Vant 自动响应系统主题
  }

  return {
    mode: themeStore.mode,
    effectiveMode: themeStore.effectiveMode,
    setMode: themeStore.setMode,
    accentColor: themeStore.accentColor,
    setAccentColor: themeStore.setAccentColor,
    applyTheme,
  }
}
```

### 路由守卫

```typescript
// router/guards.ts
// 复用 PC 端守卫逻辑，增加移动端判断
function setupRouterGuard(router: Router) {
  router.beforeEach((to, from, next) => {
    const userStore = useUserStore()

    // 未登录跳转登录
    if (!userStore.token && !to.meta.guest) {
      next('/mobile/login')
      return
    }

    // 角色权限校验
    if (to.meta.role && to.meta.role !== userStore.userInfo?.role) {
      next('/mobile/user/products')
      return
    }

    next()
  })
}
```

## 自检清单

### 类型检查
- [ ] 所有 ID 类型是否为 `string`（禁止 `number`）
- [ ] 枚举类型是否使用后端定义的值
- [ ] 可选字段是否使用 `| null` 或 `?`

### API 检查
- [ ] 请求参数是否匹配后端 DTO
- [ ] 响应数据是否正确解析

### 移动端检查
- [ ] 列表是否支持上拉加载更多
- [ ] 表单是否有防抖处理
- [ ] 抽屉是否适配键盘弹出
- [ ] 是否有安全区域适配（`env(safe-area-inset-bottom)`）
- [ ] 图片是否使用 `van-image` 的懒加载

### 代码质量
- [ ] 是否有 `console.log` 调试代码
- [ ] 重复代码是否抽取为复用函数
- [ ] 组件是否遵循单一职责原则
